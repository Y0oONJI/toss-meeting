# 기능 명세서

## 정책 결정 내역 (요약)

기획 과정에서 애매했던 지점과 그 결정 사항. 근거는 [PRD.md](PRD.md#정책-결정-사항) 참고.

- 응답 마감 기한: **있음** — 회의 생성 시 조율자가 설정 (2, 3, 10번 화면)
- 알림 채널: **없음 (pull 방식)** — 참여자/조율자가 링크 재접속 시 최신 상태만 확인 (5, 7, 12, 13번 화면)
- 다수결 동점: 이른 시간대 기본 표시, 최종은 조율자 선택 (6번 화면)
- 조율 요청 무응답: 계산에서 제외, 조율자가 임의 시점 재계산 (5, 12번 화면)
- 제출 후 재입력: 확정 전까지 허용, 확정 후 잠금 (10번 화면)

## 조율자

### 2. 회의 생성 화면

| 구분 | 내용 |
|------|------|
| 설명 | 회의 제목과 기간을 설정하는 화면 |
| 구성 요소 | 회의 제목 입력 필드 |
| | 참여 인원 수 설정 (2–20명, 기본값 6명, 스텝퍼 입력) |
| | 기간 설정 (시작일 ~ 종료일 선택) |
| | 응답 마감 일시 설정 |
| | [다음] 버튼 |
| 동작 | 제목, 인원, 기간, 마감 일시 모두 입력해야 다음으로 넘어감 |
| | 인원 수(headcount)는 참여자 응답 현황 분모로 사용 (조율자 포함 총 인원 기준) |
| 예외 케이스 | 종료일이 시작일보다 이전 → 오류 메시지, [다음] 비활성화 |
| | 과거 날짜만으로 기간 설정 시 → 오류 메시지 |
| | 제목 공백만 입력 시 → 미입력 처리 |
| | 마감 일시가 회의 기간 시작일 이후로 설정된 경우 → 오류 메시지 (마감은 회의 시작 전이어야 함) |

### 3. 초대 링크/코드 공유 및 대기 화면

> **구현 참고:** 기획 문서의 3번(코드 공유)과 4번(대기실)은 구현에서 `/host/share` 한 페이지로 통합됨 (MVP 범위).

| 구분 | 내용 |
|------|------|
| 설명 | 생성된 초대 코드를 공유하고 참여자 응답을 기다리는 화면 |
| 구성 요소 | 생성된 초대 코드 표시 |
| | 링크 복사 버튼 |
| | 참여자 응답 현황 (응답 N명 / 전체 N명, 분모는 headcount 기준) |
| | 참여자 목록 (익명, 응답 여부만 표시) |
| | [결과 확인하기] 버튼 |
| 동작 | 링크 복사 시 클립보드에 복사 |
| | 응답이 1명 이상이면 [결과 확인하기] 활성화 |
| 예외 케이스 | 전원 미응답 상태에서 [결과 확인하기] → 비활성화 |

### 4. 교집합 확인 화면

| 구분 | 내용 |
|------|------|
| 설명 | 교집합이 존재할 때 후보 시간을 보여주는 화면 |
| 구성 요소 | 가능한 시간대 후보 목록 |
| | 각 시간대별 참여 가능 인원 수 |
| | [이 시간으로 확정하기] 버튼 |
| 동작 | 조율자가 후보 선택 → 최종 확정 화면으로 이동 |
| 예외 케이스 | 후보가 여러 개일 때 참여 가능 인원 많은 순으로 정렬, 인원 수가 동률이면 이른 시간대를 기본 선택으로 표시하되 조율자가 다른 후보로 직접 변경 가능 |

### 5. 대안 제시 화면

| 구분 | 내용 |
|------|------|
| 설명 | 교집합이 없을 때 조율자에게만 보이는 화면 |
| 구성 요소 | 교집합 없음 안내 문구 |
| | 조율이 필요한 참여자 표시 (익명) |
| | 시스템 추천 시간대 (가장 많은 인원이 가능한 시간) |
| | [조율 요청 보내기] 버튼 |
| 동작 | 조율 요청 시 해당 참여자의 링크 상태를 "조율 요청됨"으로 변경 (실제 알림 전송은 없음 — 참여자가 같은 링크로 재접속해야 조율 제안 화면을 보게 됨) |
| 예외 케이스 | 조율 필요 참여자가 다수일 때 일괄 요청 (개별 발송 아님) |
| | 요청 후 끝까지 무응답인 참여자는 "불가"로 간주하지 않고 재계산 시 응답자 기준으로만 계산 (계산에서 제외) |

### 6. 다수결 결과 화면

| 구분 | 내용 |
|------|------|
| 설명 | 2회 이상 조율 실패 시 표시되는 화면 |
| 구성 요소 | 다수결 결과 안내 문구 |
| | 가장 많은 인원이 가능한 시간대 |
| | 참여 가능 / 불가 인원 수 |
| | [이 시간으로 확정하기] 버튼 |
| 동작 | 조율자가 확정 → 최종 확정 화면으로 이동 |
| 예외 케이스 | 참여 가능 인원 수가 같은 시간대가 여럿이면 이른 시간대를 기본으로 보여주되, 조율자가 다른 후보로 직접 변경해 확정 가능 |

### 7. 최종 확정 화면

| 구분 | 내용 |
|------|------|
| 설명 | 회의 시간이 확정된 후 전체 공유되는 화면 |
| 구성 요소 | 확정된 회의 시간 표시 |
| | 회의 제목 표시 |
| | 확정 시간 복사 버튼 |
| 동작 | 전체 참여자 링크 상태를 "확정됨"으로 변경 (실제 알림 발송은 없음 — 참여자가 같은 링크로 재접속하면 14번 화면이 보임) |
| 예외 케이스 | 이미 페이지를 떠난 참여자는 별도 알림을 받지 않으며, 조율자가 링크를 다시 공유하거나 참여자가 스스로 재접속해야 확정 사실을 알 수 있음 (MVP는 pull 방식) |

## 참여자

### 8. 코드 입력 화면

| 구분 | 내용 |
|------|------|
| 설명 | 초대 코드로 회의에 참여하는 화면 |
| 구성 요소 | 초대 코드 입력 필드 |
| | [참여하기] 버튼 |
| 동작 | 유효하지 않은 코드 입력 시 오류 메시지 표시 |
| 예외 케이스 | 만료/존재하지 않는 코드 → "유효하지 않은 코드입니다" |
| | 이미 확정된 회의의 코드 입력 → 확정 알림 화면으로 바로 이동 |

### 9. 정보 입력 화면

| 구분 | 내용 |
|------|------|
| 설명 | 참여자 정보와 참석 유형을 입력하는 화면 |
| 구성 요소 | 이름 입력 필드 |
| | 직급/직군 선택 |
| | 참석 유형 선택 (꼭 참석 / 가능하면 참석) |
| | [다음] 버튼 |
| 동작 | 모든 항목 입력 후 다음으로 넘어감 |
| 예외 케이스 | 이름 중복 시에도 별도 처리 없음 (참여자 간 익명이라 구분 불필요, 조율자 화면에서는 이름+직급 조합으로 구분) |

### 10. 시간대 입력 화면

| 구분 | 내용 |
|------|------|
| 설명 | 가능한 시간대를 입력하는 화면 |
| 구성 요소 | 날짜 선택 UI (기간 내 날짜 표시) |
| | 시간대 선택 UI (같은 형식으로) |
| | 복수 선택 가능 |
| | [제출하기] 버튼 |
| 동작 | 제출 시 익명 현황 화면으로 이동 |
| 예외 케이스 | 시간대 0개 선택 후 [제출하기] 클릭 → 최소 1개 선택 요구 오류 표시 |
| | 회의 기간 밖 날짜는 선택 UI 자체에서 노출 안 함 |
| | 마감 시각이 지난 후 이 화면에 접근 시 → 입력 불가, 마감 안내로 대체 |
| | 확정 전까지는 같은 링크로 재접속해 재입력(수정) 가능, 제출 시 최신 값으로 덮어씀. 확정 후에는 잠김 |

### 11. 익명 현황 화면

| 구분 | 내용 |
|------|------|
| 설명 | 다른 참여자들의 시간대를 익명으로 확인하는 화면 |
| 구성 요소 | 참여자들이 제안한 시간대 목록 (익명) |
| | 각 시간대별 제안 인원 수 |
| | 확정 대기 중 안내 문구 |
| 동작 | 확정 시 자동으로 확정 알림 화면으로 전환 |
| 예외 케이스 | 본인이 아직 시간대를 제출하지 않았다면 이 화면 자체에 진입 불가 (11번 화면으로 리다이렉트) |

### 12. 조율 제안 화면

| 구분 | 내용 |
|------|------|
| 설명 | 조율 요청을 받은 참여자에게 보이는 화면 |
| 구성 요소 | 조율 요청 안내 문구 |
| | 시스템 추천 시간대 제시 |
| | [제출하기] 버튼 |
| 동작 | 제출 시 익명 현황 화면으로 복귀 |
| 예외 케이스 | 빈 제출 불가 (최소 1개 선택 필요) |
| | 이 화면에서도 끝까지 무응답이면 5번 화면과 동일하게 계산에서 제외 처리 |
| | **MVP 범위:** "다른 시간 제안하기(직접 입력)" 클릭 시 실제 입력 UI 없이 "조율자에게 직접 연락" 안내 문구로 대체. 직접 입력 기능은 MVP에서 구현되지 않음 |

| 구성 요소 | 확정된 회의 시간 표시 |
| | 회의 제목 표시 |
